# 🚀 Real-Time Object Detection using YOLOv8 & OpenCV

## 📌 Project Overview

This project implements a Real-Time Object Detection System using YOLOv8 and OpenCV. The system is capable of detecting and identifying multiple objects in images, videos, and webcam streams with high accuracy by generating bounding boxes and confidence scores for detected objects.

The project demonstrates practical applications of Computer Vision and Deep Learning for real-time AI-powered detection systems.

---

## ✨ Features

* Real-time object detection
* Image, video, and webcam support
* Bounding box visualization
* Confidence score display
* Fast and accurate YOLOv8 detection
* OpenCV integration for frame processing
